# 小游戏 · MarbleBreaker 2.1

Kotlin + 原生 Android Canvas 的离线小游戏合集，包含 **挡板消砖** 和独立的 **数独**。从首页选择游戏，分别保存进度。无网页、广告、账号或联网权限。

## 安装

在 [Actions](https://github.com/kimizha/MarbleBreaker/actions/workflows/android.yml) 选择最新成功构建，下载 **小游戏-Android-APK** Artifact，解压安装 **小游戏.apk**。需登录 GitHub 下载 Artifact；包内有 SHA256SUMS.txt 和 COMMIT.txt，默认保留 90 天。当前为 Debug 测试签名，正式发行需要固定的 Release 签名。不同 CI 运行的临时 Debug 密钥可能不同，更新安装时可能需卸载旧测试包；请注意卸载会清除本地存档。

## 数独（独立的第二款游戏）

首页点击“数独 · 独立游戏”进入，选择简单、中等或困难。每行、每列和每个 3×3 宫均填入 1～9，不能重复。白色数字为固定题目，青色数字为玩家填写；点击格子，再用底部数字键输入。

- 离线随机生成题目，每次挖空均用求解器验证 **唯一解**。
- 三档目标线索数分别为 42、34、28；少量题目可能保留更多线索以保证唯一解。难度主要按留白数量区分，未使用人类解题技巧分级。
- 支持笔记、擦除、撤销、重做、提示和检查。填写数字时自动移除同行、同列、同宫的相同笔记，撤销可恢复这些笔记。
- 自动标红行、列、宫中的重复数字；“检查”还会标出与唯一解不同的已填数字。“提示”填入一个正确数字并累计提示次数。
- 前台游戏时计时，暂停、选难度或切后台时停止计时。填满正确答案后显示完成结算。
- 后台生成题目，不阻塞触控；新开一局前确认是否替换未完成的数独，生成期间可返回取消。
- 独立 `sudoku-v1.dat` 原子存档，保留棋盘、笔记、难度、选择格、计时、提示次数，以及最近 100 步撤销/重做记录。每次修改、暂停、退出和计时每 15 秒自动保存。
- `sudoku/` 包中的逻辑、界面、Activity、存档与挡板游戏独立；挡板关卡存档与旧版迁移格式保持不变。声音与音乐沿用应用设置。

## 挡板消砖玩法


- 每关初始 **1 颗主弹珠、3 条生命**。点击“开始”发球，单指左右拖动挡板；拖动结束不会自动发球。
- 弹珠击中挡板中央时近似竖直反弹，边缘时斜向反弹，最大角度为偏离竖直方向 65°。
- 所有普通彩色像素均 **一击消失**，没有数字或生命值。灰白特殊墙以圆点标识独立耐久。
- 弹珠漏接落出底部即消失；仅当场上所有弹珠均丢失时扣一条生命。还有生命则重新准备一颗球，否则失败。
- 清除全部彩色目标过关；无需清除不可破坏障碍。30 关逐步解锁，另有无限波次。
- 道具从被消除像素处下落，**只有挡板接住才生效**，弹珠不会收集道具。

| 道具 | 效果 |
|---|---|
| +1 / +3 / +5 | 立即从挡板附近安全位置增加弹珠，初始角度不同 |
| ×2 | 当前场上球数翻倍，包含磁力暂存的球，最多 150 颗 |
| 分裂 | 给现有球一次分裂能力；下次命中方块生成两颗额外球 |
| 加宽 | 挡板宽度由 156 增至 250，持续 16 秒 |
| 磁力 | 持续 12 秒，接住的球暂存最多 2.5 秒，可轻点屏幕提前释放 |
| 激光 | 持续 10 秒，挡板两侧每 0.5 秒发射光束，击碎首个可破坏目标；不可破坏墙会阻挡 |

总球数始终不超过 150，效果重复拾取只刷新计时或次数。丢失生命会清除临时挡板效果。

## 原创像素关卡

每关使用独立的 32×26 字符矩阵定义，字符指定颜色，18×18 的小方块位于 20×20 网格上。主题包括爱心、星星、蝴蝶、花朵、猫狗、笑脸、彩虹、宝石、城堡、圣诞树、火箭、土星、鱼、猫头鹰、蘑菇、狐狸、海龟、奖杯、雪花、水果、光谱、太极、音符、小屋、数字、迷宫与星门等。

[查看 30 关图案总览](docs/level-atlas.svg)。原始绘制规则在 `tools/generate_levels.py`，运行后生成 `core/LevelPatterns.kt` 和总览 SVG；运行时直接读取已经提交的矩阵。

6～10 关加入固定墙；11～20 关加入可破坏墙；21～25 关加入倾斜反弹板；26～30 关加入移动障碍。障碍数据独立于图案，不形成完全封闭的不可破坏包围圈。无限模式使用种子选择图案及相应阶段障碍，每波重新计算本波得分、球数和生命，最高分记录最佳单波。

## 保留功能与存档迁移

保留关卡选择、解锁、无限模式、音效、音乐、震动、低性能模式、暂停、通关结算和自动存档。进入后台自动暂停；游戏进行中每 5 秒保存，并在状态变化和退出时保存。

存档升级为版本 2，记录球位置/速度、磁力暂存、挡板位置/目标/宽度、剩余效果、生命、像素消除状态和下落道具。保留原存档文件路径，CRC32 检查、AtomicFile 写入和独立关卡进度备份不变。

读取旧版 v1 存档时保留已解锁关卡、上次关卡、最高分；由于原来的发射队列和数字方块不能转换为新玩法，进行中的旧对局在原关卡重开为 1 球、3 生命。设置仍使用原 SharedPreferences。旧格式样本包含在测试资源中。

## 构建与测试

包名 `com.kimizha.minigame`；最低 Android 8.0 / API 26；compileSdk 和 targetSdk 36 / Android 16。JDK 17、AGP 8.13.1、Kotlin 2.2.21、Gradle 8.13；原有 `.github/workflows/android.yml` 保持不变。

```sh
./gradlew :app:compileDebugKotlin :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

原始 APK：`app/build/outputs/apk/debug/app-debug.apk`。Actions 自动命名为 `小游戏.apk` 并生成 SHA-256。

挡板游戏原有 25 个单元测试覆盖：单球三生命、挡板边界和移动、中心与边缘反弹角度、实际挡板碰撞、漏接、一击消砖、特殊墙耐久、道具原位生成和下落、仅挡板收集、立即多球与 150 上限、命中分裂、加宽/磁力到期、激光阻挡、生命扣除、真实物理通关、高速薄墙和倾斜/移动障碍、30 关图案密度与多色、开放路线、磁盘存档恢复、旧版迁移、损坏拒绝、单调解锁及 150 球持续仿真。

新增 17 个数独单元测试，覆盖多难度唯一解与种子、取消生成、固定数字保护、选择与输入、笔记、冲突、候选清理、撤销/重做、提示、完成判断、计时与磁盘存档恢复、损坏文件拒绝；共 42 项测试。

CI 继续执行编译、测试、lint、APK 构建和 Android 16 模拟器测试。模拟器脚本验证进入游戏、拖动挡板、单球开球、后台暂停、强制结束后恢复，以及真实 Android 本地存档中的 v1 格式迁移，同时验证数独生成、笔记、撤销/重做、擦除、填数、提示、暂停、强制结束后的独立存档恢复，以及返回原挡板关卡进度，上传两款游戏的截图和日志。**通过情况以实际 Actions 结果为准。**

物理采用 1/240 秒固定步长、空间分区、连续圆形与旋转矩形碰撞及移动障碍的相对速度反射；异常接触会安全重定位弹珠。静态网格与查询缓冲复用，粒子和活动球数量均有上限。目标为约 60 FPS，低性能模式约 30 FPS。

尚未完成全部 30 关人工通关、多品牌真机及 150 球长时间帧率测试。开放路线测试证明目标未被固定障碍封闭，不代表穷举了全部反弹轨迹。自绘界面尚不支持 TalkBack 对每个按钮的独立焦点导航。Android 16 平板可能忽略竖屏锁定，画面会保持等比居中。

所有图形与程序合成音效均为原创，不下载素材。仅申请可关闭的震动反馈权限。签名私钥、密码和 Token 不应提交到仓库。
